# SETUP.md

## Setup

```bash
git clone https://github.com/Zh3ka21/inventory-transfer-python.git
cd inventory-transfer-python
poetry install
```

## Run the application, Docker

```bash
docker compose up --build
```

## Run tests

```bash
poetry run python test.py
```
